## Qui je suis

Je suis étudiant en **BUT Informatique** à l'IUT d'Aix-Marseille.

J'ai commencé le développement en **2021** avec **Python**, et je suis assez vite passé sur le **web**.  
Mon tout premier programme ressemblait à peu près à ça :

```python
nom = "Mathys"
print("Salut, moi c'est " + nom)
```

> Ce que je préfère, c'est vraiment la **création de sites web** : partir de rien, construire le design, et voir le résultat prendre forme directement dans le navigateur.


## MCH-Technologies

**[MCH-Technologies][mch]**, c'est mon projet, déjà en ligne : je crée des **sites internet sur mesure**, pour les artisans, commerçants et petites entreprises.

### Sites réalisés

| Site | Type |
|:----:|:----:|
| [Yakha Sport Pernes](https://yakhasportpernes.fr) | Site vitrine pour une salle de sport |
| [StudyVerse][1] | Application web pour les étudiants |

#### Comment je fais un site

1. On discute du projet avec le client
2. Je fais le design
   * la structure des pages
   * les couleurs et les polices
3. Je code le site
4. Je le mets en ligne

Pour voir le résultat, le mieux c'est encore d'aller voir [le site lui-même].
